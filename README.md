# Movie Database App

A React application that uses the TMDB API to display movies, search for movies, and view detailed information.

## Features
- Browse popular movies
- Search movies by title
- View detailed information for each movie
- Responsive UI with Tailwind CSS

## Technologies
- React
- Tailwind CSS
- TMDB API

## How to Run the Project
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.

## Folder Structure
- `src/components/`: Contains reusable UI components like Navbar, MovieCard, and SearchBar.
- `src/pages/`: Contains page components like Home and MovieDetails.
- `src/api/`: Contains functions for API calls to the TMDB API.

## API Used
- **TMDB API**: The Movie Database API for fetching movie data.
